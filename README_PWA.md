# Эволюция: установка на телефон как приложение (PWA)

Нужно один раз выложить эту папку на бесплатный хостинг с HTTPS, а потом отправлять друзьям ссылку.

## 1. Выложить в интернет (любой вариант)
- **Netlify Drop**: откройте https://app.netlify.com/drop и перетащите в окно папку `evolution-pwa` (после распаковки архива).
  Через минуту появится ссылка вида `https://что-то.netlify.app`. Зарегистрируйтесь, чтобы ссылка не удалилась.
- **GitHub Pages**: создайте репозиторий, загрузите в него все файлы из папки, затем Settings → Pages → Deploy from branch.
- **Cloudflare Pages**: Create project → Direct Upload → загрузите папку.
(Интерфейс сервисов меняется, шаги могут отличаться.)

## 2. Отправить ссылку другу в Telegram
Друг нажимает на ссылку.
- **Android**: откройте в **Chrome**. Если ссылка открылась внутри Telegram, нажмите ⋮ → «Открыть в браузере».
  Затем в игре: Настройки → «📲 Установить игру на устройство» (или меню Chrome ⋮ → «Установить приложение»).
  Иконка появится на главном экране, игра запускается во весь экран и работает без интернета.
- **iPhone**: откройте в Safari → «Поделиться» → «На экран Домой».

## 3. Обновление игры
Замените файлы на хостинге. Игра обновится при следующем запуске (иногда нужно открыть её дважды).
Сохранения хранятся в браузере устройства, при обновлении они остаются.
